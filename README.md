# SZip

Developed by **Md. Sonet Mia** — Founder, SONET, Tangail, Bangladesh. Copyright © 2026 Md. Sonet Mia.

WinRAR-এর মতো আর্কাইভ ম্যানেজার — নিজস্ব ব্র্যান্ডিং, ইংরেজি ইন্টারফেস (বাংলায় বদলানো যায়), সম্পূর্ণ অফলাইন।
ফাইল কোথাও আপলোড হয় না, ইন্টারনেট লাগে না, ইনস্টলও লাগে না (exe পোর্টেবল)।

## ভাষা (Language)

- **ডিফল্ট ইংরেজি** — প্রথমবার চালালে পুরো ইন্টারফেস ইংরেজিতে থাকে।
- বাংলা চাইলে **Options মেনু → বাংলা (Bengali)** চাপুন — মেনু, টুলবার, বোতাম, স্ট্যাটাস বার আর ডায়ালগ সাথে সাথে বাংলায় বদলে যাবে, রিস্টার্ট লাগবে না। আবার **English (default)** চাপলে ইংরেজিতে ফিরে যাবে।
- পছন্দটি `~/.szip_settings.json` ফাইলে সংরক্ষিত হয়, তাই পরের বার চালালেও আগের ভাষাই থাকবে।

## কী কী করা যায়

- **খোলা (Open):** ZIP, 7Z, TAR, TAR.GZ, TAR.BZ2, TAR.XZ, RAR
- **বানানো (Create):** ZIP, 7Z, TAR, TAR.GZ, TAR.BZ2, TAR.XZ
- **ভেতরে ঘোরা:** ফোল্ডারে ডাবল-ক্লিক করে ঢোকা, ↑ উপরে, ← পেছনে যাওয়া
- **বের করা (Extract):** সব ফাইল, শুধু বাছা ফাইল, অথবা এখানেই (Extract Here)
- **যোগ করা (Add):** আগের আর্কাইভে ফাইল/ফোল্ডার যোগ করা, নতুন আর্কাইভ বানানো
- **মোছা (Delete):** শুধু ZIP আর্কাইভ থেকে ফাইল মোছা
- **দেখা (View):** ফাইল temp-এ বের করে ডিফল্ট অ্যাপে খোলা
- **পরীক্ষা (Test):** আর্কাইভ নষ্ট কি না পরীক্ষা করা
- **খোঁজা (Find):** আর্কাইভের ভেতরে নাম লিখে খোঁজা
- **পাসওয়ার্ড:** সাধারণ (ZipCrypto) পাসওয়ার্ড দেওয়া ZIP খোলা যায়
- **সাম্প্রতিক (Recent):** আগে খোলা আর্কাইভের তালিকা

## সৎ সীমা (জেনে রাখুন)

- **RAR বানানো যায় না** — RAR প্রোপ্রাইটারি ফরম্যাট। শুধু খোলা যায়, তাও `rarfile` + UnRAR বাইনারি থাকলে।
- **AES-এনক্রিপ্ট করা ZIP খোলা যায় না** — Python-এর `zipfile` শুধু পুরনো ZipCrypto পাসওয়ার্ড বোঝে। এমন ZIP-এ নাম দেখা যাবে, বের করা যাবে না — অ্যাপ সেটা পরিষ্কার বার্তায় জানিয়ে দেবে।
- **7Z-এর জন্য `py7zr` লাগবে** — না থাকলে 7Z বন্ধ থাকবে, বাকি সব চলবে।
- **.exe/.bat ফাইল নিজে থেকে চালানো হয় না** — View করলে আগে জিজ্ঞেস করা হয়।

## পিসিতে চালানো (Python দিয়ে)

১. Python 3.10+ ইনস্টল করুন (python.org থেকে, "Add Python to PATH"-এ টিক দিয়ে)।
২. এই ফোল্ডারে কমান্ড চালান:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

ঐচ্ছিক প্যাকেজ ছাড়াও চলবে — তখন শুধু ZIP/TAR কাজ করবে।

## exe বানানো (Windows PC-তে)

`build.bat`-এ ডাবল-ক্লিক করুন। শেষে `dist\SZip.exe` পাবেন — একটাই ফাইল,
যেকোনো জায়গায় নিয়ে ডাবল-ক্লিক করলেই চলবে।

> মনে রাখবেন: Linux-এ PyInstaller দিয়ে Windows-এর exe বানানো যায় না, তাই exe
> বানাতে `build.bat` Windows PC-তেই চালাতে হবে।
